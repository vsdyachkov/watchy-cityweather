CityWeather Watchy

Firmware installer for SQFMI Watchy v2 / ESP32 devices.

Use desktop Chrome or Edge with Web Serial support. Open this page over HTTPS to install firmware.

Version 1.5

  • Connect Watchy over USB and choose the serial port in the browser dialog.
  • Do not erase device data unless you want to reset Wi-Fi and local history.
  • After flashing, reboot Watchy and configure Wi-Fi from the watch menu if needed.
